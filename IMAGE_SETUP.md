## 🖼️ How to Add Images

1. **Navigate to the service folder** you want to add images to
2. **Drop your image files** directly into that folder
3. **Supported formats**: `.jpg`, `.jpeg`, `.png`, `.webp`
4. **Recommended naming**:
   - `main.jpg` - Primary image (will be used as the main display image)
   - `image-1.jpg`, `image-2.jpg`, etc. - Additional gallery images
   - Or use descriptive names: `before.jpg`, `after.jpg`, `detail.jpg`

## 📝 Example

For the **"Baseboard Installation and Repair"** service:

1. Go to: `public/images/services/baseboard-installation-and-repair/`
2. Add images:
   - `main.jpg` (primary image)
   - `image-1.jpg` (example 1)
   - `image-2.jpg` (example 2)
   - `before.jpg` (before photo)
   - `after.jpg` (after photo)

## 🔧 How Images Are Used

Images in these folders will be automatically available for:

- **Service Detail Pages** (`/services/[service-slug]`)
- **Service Listings** (`/services`)
- **Service Category Pages** (`/services/category/[category-slug]`)
- **Portfolio Galleries**
